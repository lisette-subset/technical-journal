# Proofs, Optimal Subproblems, Dynamic Programming

In preparation for taking Georgia Tech's Graduate Algorithms course in the Fall, I am preparing by reviewing important problems in dynamic programming and their inductive proofs. 

## Longest Common Subsequence (LCS) 


### Brute Force 
The brute force approach is expensive, the general gist is to :

- enumerate all subsequences of X (extra expensive because subsequences do not need to be contiguous)
- for each enumerated subsequence, check whether it is also a subsequence of Y, but notice:
  - since each subsequence corresponds to some set of the indices of X, {1,2,..., m}, and there are $2^m$ such sets of indices, this becomes expensive quickly!


### Defining the Subproblem 
We get lucky becuase the LCS problem has an optimal substructure. We can define subproblems on the prefix of both input strings, X and Y. 

The trick is to start looking from the back of these two sequences to define the subproblem.
